# Security Policy

## Supported versions

Security fixes go into the latest stable release of Flock. Please update before reporting.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- on GitHub, under **Security → Report a vulnerability** in the affected repository, e.g.
  [flock-php/flock](https://github.com/flock-php/flock/security/advisories/new), or
- by email to security@flockphp.com.

Include what's affected, how to reproduce it, and the Flock version. We'll confirm we got your
report and keep you updated until it's fixed. Once a fix is released, we publish an advisory and
credit you unless you'd rather we didn't.
